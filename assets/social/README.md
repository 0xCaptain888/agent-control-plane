# Social assets

These SVGs are reusable launch and submission graphics. They contain no
wallet secrets, API credentials, remote scripts, or embedded third-party
resources.

| Asset | Best use |
| --- | --- |
| `agentguard-hero.svg` | Project announcement, submission cover, repository preview |
| `agentguard-lifecycle.svg` | Technical thread explaining policy → verify → settle |
| `agentguard-job-614.svg` | BNB Agent Studio proof post and follow-up evidence |

The Arbitrum V3 transaction links in the repository and Marketplace are the
canonical live proof. Social graphics are presentation assets, not substitutes
for on-chain evidence.
