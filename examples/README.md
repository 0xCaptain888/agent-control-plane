# Examples

Examples are vertical applications. They demonstrate how one stable control plane can be packaged for different hackathon tracks without forking the core.

Recommended exchange-track entry point:

- `examples/okx-trade` — a judge-ready OKX flow with approved, pre-adapter blocked, and post-execution frozen outcomes.

Recommended BNB Agent Studio entry point:

- `examples/bnb-agent-marketplace` — discover, compare, hire, verify, and settle a SafeSwap Agent with verified, blocked, and frozen outcomes.
